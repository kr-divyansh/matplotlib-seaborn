# 📊 Matplotlib & Seaborn — Data Visualization with Python

Welcome to my **Matplotlib and Seaborn** repository! This repository contains Python notebooks, examples, and practice projects focused on data visualization, statistical analysis, and Exploratory Data Analysis (EDA).

## 🎯 Objectives

- Learn the fundamentals of data visualization using Python.
- Create informative charts and graphs.
- Perform Exploratory Data Analysis (EDA).
- Understand statistical patterns, trends, and relationships in datasets.
- Improve data analysis and visualization skills for Machine Learning projects.

## 🛠️ Technologies Used

- **Python** — Programming language
- **Matplotlib** — Creating customizable plots and charts
- **Seaborn** — Statistical data visualization
- **NumPy** — Numerical computing
- **Pandas** — Data manipulation and analysis
- **Jupyter Notebook** — Interactive coding and visualization

## 📈 Topics Covered

### Matplotlib
- Line Plots
- Bar Charts
- Scatter Plots
- Histograms
- Pie Charts
- Subplots
- Figure and Axes customization
- Titles, labels, legends, and styling

### Seaborn
- Distribution Plots
- Box Plots and Violin Plots
- Count Plots
- Heatmaps
- Pair Plots
- Regression Plots
- Categorical Data Visualization
- Correlation Analysis
